# Polynomial Lyapunov functions

`global_z3.py` demonstrates symbolic polynomial synthesis followed by
independent verification. The method is developed in:

> J. Liu and M. Fitzsimmons, “Symbolic Reduction for Formal Synthesis of
> Global Lyapunov Functions,” *QEST+FORMATS*, 2025.
> [doi:10.1007/978-3-032-05792-1_18](https://doi.org/10.1007/978-3-032-05792-1_18)
