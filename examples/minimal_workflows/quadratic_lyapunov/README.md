# Quadratic certificates

This folder contains the minimal quadratic Lyapunov and control-Lyapunov
workflows. The scripts demonstrate bounded and global verification with Z3,
dReal, and CROWN.

The global inverted-pendulum example appeared in:

> J. Liu, Y. Meng, M. Fitzsimmons, and R. Zhou, “LyZNet: A Lightweight Python
> Tool for Learning and Verifying Neural Lyapunov Functions and Regions of
> Attraction,” *HSCC*, 2024.
> [doi:10.1145/3641513.3650134](https://doi.org/10.1145/3641513.3650134)
